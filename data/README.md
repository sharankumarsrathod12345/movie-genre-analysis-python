# Data provenance

These CSVs were supplied by the project author as course-project inputs and were already uploaded to this repository. Exact original dataset and lesson URLs, and third-party reuse terms, remain to be confirmed. The repository code license does not grant rights to third-party data or case materials.

- `imdb_movies.csv`: 10,866 source rows and 21 columns. The filename alone does not establish the original provider.
- Observed release years: 1960–2015. One exact duplicate is removed; 23 movies lack genres.
- Currency, monetary adjustment conventions, and the definition of the popularity score need original-source documentation.

Input SHA-256 hashes are recorded in `../docs/reproducibility.json`.
